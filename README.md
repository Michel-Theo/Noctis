# NOCTIS

Site vitrine et boutique de bagues en argent, dans un univers gothique et cybersigilism. Projet personnel pour mon portfolio.

## Contenu

- `blender/` : sources 3D des bagues (`thorn_ring.blend`, stocké avec Git LFS) et rendus.
- `assets/models/` : modèles prêts pour le web au format GLB. `ring_tribal.draco.glb` (136 Ko) est compressé avec Draco.

## Workflow Git

- `main` : version en ligne.
- `develop` : branche d'intégration.
- `feature/<nom>` : une branche par fonctionnalité, créée depuis `develop` et fusionnée par PR.
